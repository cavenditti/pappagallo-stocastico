# Font

Gli stessi delle slide, serviti dal portatile perché in sala i telefoni non hanno Internet.
Solo il sottoinsieme latino (comprese le lettere accentate), in woff2, presi da Google Fonts.

| file | font | licenza |
|---|---|---|
| `fredoka.woff2` | Fredoka (variabile, pesi 400–700): titoli e frasi | SIL Open Font License 1.1 |
| `nunito-sans.woff2` | Nunito Sans (variabile, pesi 400–700): testo | SIL Open Font License 1.1 |
| `jetbrains-mono.woff2` | JetBrains Mono 500: numeri e timer | SIL Open Font License 1.1 |

Testo della licenza: https://openfontlicense.org. Se il repository diventa pubblico, aggiungi
qui il file `OFL.txt` di ciascun font (dalla sua pagina su Google Fonts).
